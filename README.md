# Data Structure and Algorithms

This repository contains C++ implementations and practice problems for common data structures and algorithms. It is organized by topic to make it easy to study, revise, and practice problem-solving patterns.

## Overview

The repository covers:

- Arrays
- Binary Search
- Binary Search Tree
- Bit Manipulation
- Dynamic Programming
- Graphs
- Greedy Algorithms
- Hashing
- Heaps
- Linked Lists
- Number Theory
- Recursion
- Searching
- Sorting
- Sliding Window and Two Pointers
- Stacks
- Strings
- Trees
- Tries
- Queues
- Pattern Matching

## How to Use

1. Pick a topic folder based on the concept you want to study.
2. Open any C++ file and read the problem statement, logic, and implementation.
3. Compile and run the file using a C++ compiler.
4. Modify the code to experiment with different inputs and edge cases.

## Example Compilation

On Linux or macOS:

```bash
g++ file_name.cpp -o file_name
./file_name
```

On Windows with MinGW or g++:

```bash
g++ file_name.cpp -o file_name.exe
file_name.exe
```

## Notes

- This repository is intended mainly for learning and practice.
- Some files may be focused on brute-force and optimized approaches together.
- Many problems include multiple solutions, such as brute force, better, and optimized versions.
- Use the files as reference material while solving problems on your own.

## Suggested Learning Path

1. Start with Arrays and Strings.
2. Move to Hashing, Searching, and Sorting.
3. Learn Stacks, Queues, and Linked Lists.
4. Practice Recursion and Trees.
5. Study Graphs, Dynamic Programming, and Greedy algorithms.
6. Finish with advanced topics like Trie, Heaps, and Number Theory.

## Goal

The main goal of this repository is to strengthen understanding of core data structures and algorithmic thinking through consistent practice and implementation.
